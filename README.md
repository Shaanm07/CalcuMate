# CalcuMate

Interactive online calculator (HTML/CSS/JS).

## Features
- Basic arithmetic: +, −, ×, ÷
- Utility keys: AC (all clear), DEL (backspace), = (equal)

## Files
- `index.html`, `index.css`, `index.js` 

## Getting started
1. Clone the repository (git clone https://github.com/shaanmehta/CalcuMate.git)
2. Open index.html
